# BUILD-HISTORY.md: Finished phases

Phases of [BUILD.md](BUILD.md) whose every item is ticked are moved here
unchanged, with all their notes and results, so that BUILD.md holds only
the work still ahead (AGENTS.md §8, "Keeping BUILD.md short"). Sessions do
not read this file by default. Open it only when an open item, a document,
or a failing check refers to a finished item and you need its evidence.

Entries are a record: never edit one except to repair a broken link. A
finished item that later proves broken gets a new item in the earliest open
phase of BUILD.md.

still have an open item (P0.7 and P0.8 wait on [GATE DEMO], P1.12 on the
